# ZG Construções — site

Site da loja (já montado) e o pacote do servidor da loja.

- `index.html` e `assets/`: o site publicado no Vercel (sem etapa de build).
- `servidor/funcao.js`: servidor da loja, usado pela função `loja` do Supabase.

O código-fonte e o programa do caixa ficam fora deste repositório. Não edite estes arquivos à mão:
eles são gerados a partir do projeto Caixa & Estoque.
